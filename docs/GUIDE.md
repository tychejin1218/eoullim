# 어울림 사용 가이드

팀원용 안내입니다. 사주나 명리를 몰라도 읽을 수 있게 썼습니다.

---

## 이게 뭔가요

팀원들의 생년월일로 **서로 일하는 방식이 어떻게 다른지** 살펴보는 도구입니다.
잘 맞고 안 맞고를 가리는 게 아니라, "이 사람은 이렇게 움직이는구나"를 미리 알아두고
회의나 역할 나눌 때 참고하자는 쪽에 가깝습니다.

> 팀 빌딩 아이스브레이킹용입니다. 업무 배정이나 평가의 근거로 쓰지 마세요.

---

## 쓰는 법

### 1. 내 코드 만들기

`내 코드 만들기` 탭에서 이름, 직무, 생년월일시를 넣고 **사주 계산하기**를 누릅니다.

직무는 안 골라도 됩니다. 고르면 결과에 "이 직무를 이런 방식으로 한다"는 설명이 하나 더 붙습니다.

### 2. 코드만 공유하기

이런 코드가 나옵니다.

```
지영|庚午辛巳庚辰癸未|BE     ← 직무를 고른 경우
지영|庚午辛巳庚辰癸未        ← 안 고른 경우
```

**팀 채팅방에는 이 코드만 올리면 됩니다.** 생년월일을 알릴 필요가 없습니다.

### 3. 팀 보기

팀장(또는 아무나)이 `팀 보기` 탭에서 모인 코드를 붙여넣습니다.
여러 줄을 한 번에 넣을 수 있고, 한 명만 넣어도 동작합니다.

---

## 내 생일은 안전한가요

- **생년월일시는 이 브라우저 밖으로 나가지 않습니다.** 서버로 보내지 않습니다.
- 공유하는 코드에는 **여덟 글자(팔자)만** 들어 있습니다.
- 같은 팔자는 60년 주기로 반복되기 때문에, 코드만으로는 생년월일을 알아낼 수 없습니다.
- 팀 목록은 내 브라우저에만 저장됩니다. 다른 사람에게 전달되지 않습니다.

생일을 알리고 싶지 않은 사람도 참여할 수 있습니다.

---

## 결과 읽는 법

### 팀 오행

사주에서는 사람의 기운을 다섯 가지로 나눠 봅니다. 팀 전체가 어떤 힘이 많고 적은지 보여줍니다.

| | 무슨 힘인가 | 팀에서 하는 일 |
| --- | --- | --- |
| **목** 木 | 새로 시작하고 밀어붙이는 힘 | 없던 일을 벌이고 첫 삽을 뜸 |
| **화** 火 | 표현하고 분위기를 움직이는 힘 | 알리고 설득하고 판을 달굼 |
| **토** 土 | 중심을 잡고 안정시키는 힘 | 흔들릴 때 기준을 잡아줌 |
| **금** 金 | 기준을 세우고 끊어내는 힘 | 안 할 것을 정하고 매듭지음 |
| **수** 水 | 넓게 보고 정보를 모으는 힘 | 먼저 알아보고 검토함 |

다섯이 고르면 각 20%입니다. 한쪽이 지나치게 얇거나 두꺼우면 화면에서 따로 짚어줍니다.

예를 들어 **목이 얇은 팀**은 있는 걸 다듬는 데는 강한데 0을 1로 만드는 일이 잘 안 나옵니다.
그럴 때 "킥오프에서 아예 다른 방식을 한 번은 꺼내보자" 같은 팁이 같이 나옵니다.

### 페어 매트릭스

두 사람씩 짝지어 100점 만점으로 봅니다. 칸을 누르면 그 조합의 설명이 나옵니다.

**낮은 점수가 "안 맞는 사람"이라는 뜻이 아닙니다.**
방식이 다를수록 낮게 나오고, 오히려 그래서 서로 보완이 됩니다.
가장 낮은 조합에도 "이렇게 하면 강점이 된다"는 팁이 붙습니다.

> 예: 점수가 낮은 조합에 이런 설명이 붙습니다.
> *"보는 각도가 정면으로 다름. 회의는 길어지지만, 팀이 놓친 구멍은 거의 항상 이 두 사람 사이에서 발견됨.
> 팁: 결론 없는 토론이 길어지면 시간을 끊고 서면으로 전환할 것."*

점수는 일간 40 + 일지 35 + 오행 보완 25로 계산하고, 최저는 30점입니다.

### 일하는 방식

각자 가장 두꺼운 기운을 **일하는 방식**으로 옮긴 것입니다. 직무가 아니라 "어떻게 움직이는가"입니다.

| 방식 | 어떤 유형인가 |
| --- | --- |
| 직접 끌고 가는 쪽 | 혼자 맡아 끝까지 가는 일에서 힘이 붙음 |
| 꺼내고 알리는 쪽 | 아이디어를 내고 밖으로 설명하는 데 강함 |
| 굴러가게 만드는 쪽 | 현실 감각이 좋아 범위와 자원을 조율함 |
| 기준을 지키는 쪽 | 리스크를 미리 보고 기준을 지키게 함 |
| 깊이 파는 쪽 | 구조를 잡고 근거를 모으는 데 강함 |

아무도 맡지 않았고 팀 전체에도 얇은 방식이 있으면 **비어 있음**으로 따로 표시됩니다.
"이건 누군가 명시적으로 맡자"는 신호로 보시면 됩니다.

### 직무

**직무는 각자 고른 값입니다. 사주로 직무를 추천하지 않습니다.**
프론트엔드인 사람에게 "당신은 디자이너 체질"이라고 말해봐야 쓸모가 없으니까요.

대신 **직무 × 일하는 방식**을 겹쳐 봅니다.

> 지영 · 백엔드 · 직접 끌고 가는 쪽
> *도메인을 통째로 맡아 끌고 감. 설계 주도권을 넘기는 것을 답답해함.*

> 태경 · 프로젝트 매니저 · 깊이 파는 쪽
> *결정 전에 근거를 충분히 모음. "빨리 정해달라"는 재촉에 스트레스를 크게 받음.*

같은 직무가 둘 이상인데 **일하는 방식까지 같으면** 따로 짚어줍니다.
손발은 잘 맞지만 놓치는 지점도 똑같아서, 한 명이 다른 축을 맡는 편이 안전하다는 뜻입니다.

## 자주 묻는 것

**태어난 시간을 몰라요**
`모름`을 체크하면 시주를 뺀 세 기둥으로 계산합니다. 결과는 정상적으로 나옵니다.

**23시가 넘어서 태어났어요**
시와 분을 정확히 넣어주세요. 23시 30분 이후는 계산 방식이 달라져서, 대충 넣으면 결과가 바뀝니다.

**음력 생일이에요**
`음력`을 고르면 됩니다. 윤달이면 윤달 체크박스가 나타납니다 (그 해에 윤달이 있는 달에서만).

**결과 이미지로 남기고 싶어요**
`이미지로 저장` 버튼을 누르면 진단 전체가 PNG로 저장됩니다.

**직무를 꼭 골라야 하나요**
아니요. 안 고르면 직무 관련 설명만 빠지고 나머지는 그대로 나옵니다.
목록에 없는 직무면 `그 외`를 고르시면 팀 구성에는 잡힙니다.

**결과가 저랑 안 맞는 것 같아요**
그럴 수 있습니다. 재미로 보는 도구입니다.
다만 태어난 시각이 정확한지, 양력/음력을 제대로 골랐는지는 한 번 확인해보세요.
