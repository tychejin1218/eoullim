# Corpus Rules

`corpus.ts`의 문장은 **동료가 서로에 대해 읽는 글**이다. 정확도보다 이 사실이 먼저다.

## 절대 규칙

1. **사람을 평가하지 않는다.** 항상 "두 사람 사이의 방식 차이"로 쓴다.
   - ✗ "고집이 세서 협업이 어려운 유형"
   - ✓ "목표는 같은데 접근 속도가 달라서, 맞물릴 땐 추진력이 배가 되고 어긋날 땐 주도권 다툼처럼 보임"
2. **모든 항목에 실행 가능한 `tip`을 붙인다.** 진단만 하면 뒷담화가 되고, 팁이 붙으면 회의 도구가 된다.
3. **나쁜 조합은 없다.** 점수가 가장 낮은 `충`·`극`도 "이렇게 하면 강점이 된다"로 닫는다.
   `충`은 "부딪히는 대신 서로를 움직이는 / 팀이 놓친 구멍은 여기서 발견된다"로 쓴다.
4. **어투는 개조식 종결**(`~함`, `~임`)로 통일한다.

## 구조 제약

- 모든 테이블은 `Record<K, V>` 타입이다. 키를 빠뜨리면 컴파일 에러가 난다 — 타입을 느슨하게 풀지 않는다.
- 방향이 있는 항목(`생`, `극`, `ELEMENT_COMPLEMENT`)에서 **`{A}`는 항상 주는 쪽·조이는 쪽**이다.
- 치환자 뒤의 조사는 `{A}가`처럼 그냥 쓴다. `fillNames()`가 받침을 보고 이/가·은/는·을/를을 고른다.
  직접 "이(가)" 같은 표기를 쓰지 않는다.

## 점수를 건드릴 때

`SCORE_WEIGHT`는 일간 40 / 일지 35 / 보완 25, 바닥 30점이다.
바닥 30점은 **낮은 숫자가 낙인이 되지 않게** 하려는 장치다. 없애지 않는다.
수정 후 `npm test`로 `test/distribution.test.ts`를 통과하는지 확인한다.
