# Core Rules

`src/core/`는 브라우저 없이 Node에서 돌아야 한다. 이 제약이 테스트를 빠르고 단순하게 유지한다.

## 순수성

- `document`, `window`, `localStorage` 등 DOM API 참조 금지
- React import 금지 — 훅이 필요하면 `src/ui/`에 둔다
- 부수효과 없는 함수로 작성한다. 파일 쓰기는 테스트(리포트 생성)에서만 한다
- 예외: `truesolar.ts`의 `Intl.DateTimeFormat`은 Node·브라우저 양쪽에 있으므로 허용

## 만세력 함정 (실제로 틀렸던 것들)

| 함정 | 규칙 |
|---|---|
| 야자시 | 시각을 12시진으로 묶지 않는다. `hour`/`minute`를 그대로 받아 `lunar-typescript`에 넘긴다 |
| 진태양시 | 표를 직접 만들지 않는다. `koreaOffsetMinutes()`가 tzdata에서 조회한다 |
| 음력 일수 | 달마다 29/30일이 다르다. `lunarMonthDayCount()`로 조회하며 30일을 가정하지 않는다 |
| 자시 유파 | `sect: 2`(야자시설)가 기본. 유파 차이지 버그가 아니므로 옵션으로 남긴다 |

## 명리 규칙을 추가·수정할 때

1. **판정 우선순위를 주석으로 남긴다.** 한 쌍이 두 관계에 동시에 걸리는 경우가 흔하다
   (巳申은 육합이자 삼형, 丑未는 충이자 형, 천간합은 전부 상극 위에 성립).
   우선순위를 정하지 않으면 조용히 틀린다.
2. **테스트를 먼저 쓴다.** 기대값은 추측하지 말고 실제로 계산해 확인한 뒤 박는다.
3. **가중치나 임계값을 바꾸면 `test/distribution.test.ts`를 돌린다.** 실제 생년월일
   200명(19,900쌍) 기준 분포 가드다. 깨지면 임계값을 실제 표본으로 재튜닝한다.

## 임계값은 팀 크기에 휘둘린다

인원이 많을수록 평균이 균등에 수렴하므로, 고정 %로 자르면 작은 팀에서만 경고가 쏟아진다.
그래서 `team.ts`는 잘라내는 대신 `severity`(0~1)를 항상 주고 `notable` 플래그로 강조 여부만 정한다.
새 진단을 추가할 때도 같은 방식을 쓴다.
